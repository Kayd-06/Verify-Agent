log_0002 · architecture

Two agents.
Zero shared context.

The Worker acts. The Verifier re-derives the correct answer independently — without ever reading the Worker's claims — then diffs the outputs field by field.

W1 · Worker Agent

Reads. Classifies. Acts.

Polls the Gmail inbox, classifies each support thread, and writes structured actions to Notion and Slack. Logs every operation with a content hash.

  • Gmail polling with SHA-1 deduplication
  • Gemini classification (bug / billing / feature / other)
  • Notion ticket create/update
  • Slack status post to #verity-status
  • Appends to shared/action_log.jsonl
⇄
V2 · Verifier Agent

Re-derives. Diffs. Remediates.

Watches the action log, independently asks Gemini "what should the target ID be?", fetches the actual Notion state with settle-window retries, and runs a field-by-field structural diff.

  • V2a: Independent target re-derivation (no peeking at W1's claims)
  • V2b: Settle-window retries — 500ms → 1s → 2s backoff
  • V3: Structural diff — wrong_target / no_op_claimed / incomplete
  • High confidence → auto-revert in Notion
  • Low confidence → escalate to #verity-alerts

log_0004 · verification_gates

Three gates. One verdict.

Every action passes through three independent verification checks before a verdict is written to verifications.jsonl.

⊙

V2a · Target Re-Derivation

Verifier independently asks the LLM: "What should the Notion target ID be?" Without reading the Worker's claimed target. If IDs diverge → wrong_target.

⟲

V2b · Settle-Window Retry

Fetches actual Notion state with exponential backoff — 500ms, 1s, 2s — to absorb read-after-write races before committing to a diff result.

≠

V3 · Structural Field Diff

Compares the Worker's claimed_state (full intended ticket fields) against the actual Notion DB record field by field. Any mismatch → classified failure.

log_0005 · trust_report

Trust, but
verify.

The Verity stack runs silently alongside your agent, writes verdicts to a local JSONL audit trail, and surfaces anomalies before your users see them.

🔍

Autonomous re-derivation

The verifier never reads the Worker's claims. It independently derives the correct answer from raw source data — just like a human auditor would.

⚡

Auto-remediation at high confidence

Structural mismatches (wrong_target, no_op_claimed) trigger an automatic Notion revert. No human intervention required.

🔔

Escalation at low confidence

Semantic divergences — where the structure matches but the intent may not — are flagged to #verity-alerts for human review.
